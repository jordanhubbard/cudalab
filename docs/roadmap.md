# Roadmap

## 0.1 — The live pixel laboratory

- Native Linux/Windows studio shell
- Manifest gallery, editable source, preview, output
- NVRTC hot compilation with last-good-module behavior
- CUDA/OpenGL zero-host-copy preview
- Device/compiler telemetry and kernel timing
- Spectrum, CUDA Cosmos, and Mandelbulb Cathedral

## 0.2 — Stateful compute

- `setup`, `update`, and `teardown` device-module lifecycle
- Persistent named buffers and texture/surface objects
- Stream-ordered allocator and multi-stream scheduler
- CUDA graph capture/replay with parameter updates
- Save-as/new package, file tree, tabs, dirty-close flow, syntax highlighting
- Reaction-diffusion, million-body gravity, fluid, and particle-fluid pieces

## 0.3 — Modern architecture gallery

- Capability-aware manifests and portable fallbacks
- Cooperative groups and cluster-launch examples
- Async copy pipelines and distributed shared memory
- FP16/BF16/FP8 tensor-core visual pieces using maintained CUDA libraries
- Occupancy, registers, memory throughput, and timeline inspector
- Headless compile/render tests and golden-image tolerances

## 0.4 — Media and libraries

- cuFFT audio/spectral studio
- NPP image pipeline and video ingest/export
- cuBLASLt/CUTLASS experiments
- Vulkan external-memory backend; D3D12 interop on Windows
- Screenshot and recording/export pipeline

## 1.0 — A demoscene instrument

- Score/timeline authoring and deterministic seeking
- Multi-part productions with resource prewarming
- Optional audio-master clock and tracker playback
- Package import/export and distributable standalone player
- A flagship production that earns the hardware
